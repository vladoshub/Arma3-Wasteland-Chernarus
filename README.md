Wasteland.cup_chernarus_A3

A heavily modified Arma 3 Wasteland mission for Chernarus using CUP content.

This mission is still under active development and is not considered finished. Contributions are welcome — if you have improvements for shops, airdrops, AI loadouts, missions, balancing, or other systems, feel free to open a Pull Request.
